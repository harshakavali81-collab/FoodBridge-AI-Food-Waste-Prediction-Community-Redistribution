# FoodBridge AI — portfolio case study

![Hero](../docs/assets/01-hero-banner.svg)

**Challenge:** Anticipate surplus and coordinate suitable food donations without claiming automated food safety.

**Solution:** An educational full-stack proof of concept with validated inventory, human screening, conservation of reserved stock, recipient matching, synthetic analytical trends and time-aware offline forecasting.

**Engineering:** Python, SQLAlchemy, FastAPI, React, Recharts, Scikit-learn, Docker and GitHub Actions.

**Responsible boundary:** All data is synthetic; recipient verification is illustrative. Human-confirmed pickups are the only operationally counted collected amount. No live partner integrations or public deployment are claimed.
