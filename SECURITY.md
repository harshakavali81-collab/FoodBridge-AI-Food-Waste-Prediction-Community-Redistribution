# Security Policy

FoodBridge AI is currently a synthetic-data educational demonstration. There is no production deployment or food-distribution operational authorization. Do not put secrets, identifiable beneficiary data or real partner credentials in issues, pull requests or demo datasets.

To report a vulnerability, use GitHub's private vulnerability reporting feature if enabled on this repository, otherwise contact the maintainer using a non-public channel. Include reproducible steps, affected version and potential impact without posting live tokens.

The internal staging service blocks all operational mutations by design. See [docs/SECURITY_READINESS.md](docs/SECURITY_READINESS.md) for gaps that must be resolved before serving real users.
